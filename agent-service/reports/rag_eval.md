## 单变量组件归因分析

1. **Dense → Hybrid 无改写（`Recall@5`: 84.07% → 77.41%，差值 -6.66 pp）**：未经术语对齐的口语词汇（如“买完多久能赔”“后悔退保”）进入 BM25 稀疏检索易匹配到大量无关段落噪声，直接 RRF 融合反而稀释语义精排位次。
2. **+ 领域词典改写（`Recall@5`: 77.41% → 87.04%，净提升 +9.63 pp）**：将口语映射为精算标准术语（等待期/犹豫期/责任免除/减保等）后，BM25 精准命中条目标题，显著扭转稀疏检索劣化。
3. **+ 并行定额与路径去重（`跨产品对比完整率`: 40.00% → 80.00%，`Top-5 重复块率`: 5.30% → 0.00%）**：单次过滤易被密集单品霸榜，并行定额 + Round-Robin 直接打通多品对比覆盖，`(clause_name, section_path)` 去重彻底消除共享 PDF 重复父块。
4. **+ gte-rerank-v2 重排（`Recall@5`: 88.89% → 96.67%，`MRR`: 0.7667 → 0.9074，P95 +1362.2ms）**：在高质量初筛集上叠加 Cross-Encoder 重排进一步提升首条命中率。
5. **最终方案 vs HyDE 竞品（`Recall@5`: 96.67% vs 87.41%，P95: 1642.8ms vs 3584.2ms）**：规避 HyDE 假设条款生成的数值幻觉与额外生成延迟，兼具更好召回与更低延迟。
